# 张鑫旭 · 个人主页

简洁、响应式的静态个人网站，无需安装依赖或构建。

网站地址：https://Rerke7781.github.io/myWeb/

## 修改内容

- `index.html`：中文主页。
- `en.html`：英文主页；两页通过顶部和底部的语言链接相互切换。
- 修改个人信息时，请同步更新两个页面。
- `style.css`：布局、字体与颜色，包含手机端与打印样式。
- `favicon.svg`：网站图标。

本地预览：在仓库目录执行 `python -m http.server 8000`，打开 http://localhost:8000。

## GitHub Pages

使用 `main` 分支根目录发布。修改文件并推送到 `main` 后，GitHub Pages 自动更新。

本网站仅展示公开个人简介，没有上传原始简历或公开电话号码。
